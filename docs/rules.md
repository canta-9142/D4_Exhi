# ゲームのルール v1.0

## ノードとパケット

- プレイヤーノードは8個（A〜H）、ボットノードは3個（I〜K）。
- ノード同士は決められた経路で接続されている。
- パケットには、それぞれ目的地が設定されている。
- 各ノードには転送待ちのパケットが蓄積する。
- 各プレイヤーノードに、1pkt/sのペースで、宛先が自分以外のプレイヤーノードに設定されたパケットが自動生成される。
- ボットノードを出発地点として新たに生成されることはない。

## スコア

- 1ゲーム120秒で得られたスコアを競う
- 自分が発信した・中継したパケットが目的地に到達した時点でスコアとして加算される。
  - 2ホップ以内: 発信した人に15点、中継した人に8点
  - 3ホップ以上: 発信した人に10点、中継した人に8点
- パケットが「パケットロス」となった場合、そのパケットによってスコアが加算されることはない。
- ゲーム終了時に到着していないパケットは、スコアとして加算されない。

## パケットの転送

プレイヤーは、接続された隣接ノードから転送先を選択する。

転送対象は常に自分のノードで最も古いパケット（FIFO）。

プレイヤーはパケットを任意に選択したり、接続されていないノードに直接送信したりすることはできない。

## 自動操作

自動転送はどのノードであったとしても事前に計算された優先順位に従って行われる。状況による優先順位の変更もない。

### プレイヤーノード

Webの管理画面から、プレイヤーノードを自動操作に切り替えることができる。

また、対応するプレイヤーMCUが切断された場合も、自動操作に切り替わる。

自動操作では、パケット生成のルールは変わらず、2pkt/sのペースでパケットの自動転送を行う。

得点方法は手動操作と同じであり、自動操作中もスコアを計算・表示する。

ランキング資格はゲーム単位で管理する。ゲーム開始時に自動操作であった場合、またはゲーム中に一度でも自動操作へ切り替わった場合は、そのゲームのランキング対象外とする。

### ボットノード

ボットノードは常に自動操作モードで動作する。

ボットノードの自動転送は1pkt/s、保持できるパケット数は4件である。

## パケットロス

### 輻輳

転送先のボットノードのバッファが満杯の場合、転送したパケットは破棄され、パケットロスとなる。

### タイムアウト

このゲームのパケットのTTLは一律5であり、ノード間を転送されるたびに1減少する。TTLが0になった時点で目的地に到着していないパケットは、パケットロスとなる。

### ネットワークループ

すでに通ったことのあるノードにパケットが到着した場合、そのパケットは破棄され、パケットロスとなる。
